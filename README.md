# Creative Commons Asset Finder 
The Creative Commons Digital Asset Finder is a search interface for Wikimedia Commons — a repository of over 100 million freely reusable media files operated by the Wikimedia Foundation. It is designed for researchers, educators, and cultural heritage practitioners who need openly licensed media with full rights and descriptive metadata.

Supported media types include images, audio recordings, and video. All assets carry Creative Commons or equivalent open licenses. Each result surfaces a complete Dublin Core metadata record — including creator, rights, license, format, extent, and spatial coverage where available.

Data is retrieved live from Wikimedia Commons. No data is stored locally; results always reflect the current state of the repository.
